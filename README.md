# Luis Ayala Business Website

This is a static website for a business/homepage project built with HTML, CSS, and JavaScript.

## Files
- `index.html` – homepage
- `styles.css` – main styling
- `script.js` – small front-end scripts
- `about-page.html` – about page
- `contact-us.html` – contact page
- `services.html` – services page

## Run locally
Open `index.html` in a browser, or serve the folder with a local static server.
